# Đĩa chiến lược có sẵn

Mỗi file `.md` ở đây là một **đĩa**: phần đầu (giữa hai dòng `---`) khai báo chiến lược dùng khung nào và bật khối nào,
phần dưới giải thích bằng chữ. Hộp (bot + web) đọc các đĩa này khi chạy. Hướng dẫn đầy đủ: `docs/HOP_VA_DIA.md`.

Đĩa có sẵn không ghi tham số (`params`) nên vẫn lấy theo `.env` như trước — kết quả PP1–PP7 không đổi.
Đĩa nạp từ web lưu ở `data/strategies/` (không commit).
